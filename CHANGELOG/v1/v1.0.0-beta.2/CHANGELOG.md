# v1.0.0-beta.2

## 🚀 主要更新

- 新增 **集控**：在「设置 → 集控」里填地点 ID 和网页上生成的一次性配对码，就能把这块作业板接进 SECTL 集控中心——老师在网页控制台上能看到这台设备在不在线、在哪个班，也能在那边换班；本机设置里同样能直接换；设备名、设备 ID、连接状态都在这一页，想彻底断开就点「清空」
- 新增 **作业自动备份**：开着集控时，作业板一有改动就把最近一周的作业连手写笔迹一起传到集控，老师能翻到每天布置了什么；断网先攒着，连上自动补传，内容没变不会重复传。设置里能看到最近一次备份成功的时间，一直传不上去才会提醒一次
- 新增 **考试看板同步**：考试安排也跟着传，老师不用走进教室就知道这周考什么、下一场是几点
- 新增 **考试看板布局**：标题、时钟、考试信息、考试表格、左下角退出区这五块的位置和大小都能改，拖着挪或用右侧数值精调，横向会自动对齐到 12 栏、纵向对齐到整 1%；未开始 / 即将开始 / 进行中 / 已结束四档各存一套，在独立的全屏编辑窗里拿示例考试和假时钟预览，点「完成」才写回，点「取消」就丢掉
- 新增 **考试看板主题**：看板上的 13 处颜色都能换，自带午夜自习、纸张、黑板、专注、高对比五套预设，也能跟随应用外观，或在某套底色上逐项改（连透明度一起调）；单项能重置，也能整套恢复默认
- 新增 **考试看板窗口**：一份看板一张卡，卡上的「放映」直接放那一块，不用先「设为当前」；新建看板、快速布置、导入考试都收在这一页，托盘菜单里也能直接打开
- 新增 **作业里的链接**：布置作业的工具栏多了「插入链接」，选中文字就直接套上、没选中就插「文字 + 地址」，卡片上的链接点一下就打开；不想让链接可点，可以在「设置 → 作业板 → 内容与样式」里关掉

## 💡 功能优化

- 优化 **再次打开**：已经开着的时候再双击图标，默认直接把考试看板窗口摆到眼前（以前只会问一句「重启还是取消」）；想换成全屏放映、看板模式或每次都问，在「通用 → 再次打开时」里挑
- 优化 **收纳**：收纳按钮从「更多」菜单提到标题栏，上课要收板子一眼就找得到；浮钮改成不置顶，收起来之后不会压在课件上被误碰；板子置底时它仍旧跟着沉到桌面层
- 优化 **考试自动清理**：结束超过一周的考试自动从看板上收掉，刚考完的先留一周，方便核对成绩和补录
- 优化 **作业文件自动刷新**：作业文件被外部改动（另一台设备同步过来、老师从集控下发、自己拷贝替换文件）后，作业板和看板模式会自己换成新内容，不用重启应用；自己保存时不会白刷一遍
- 优化 **设置**：收纳只留「窗口与收纳 → 收纳作业板」一个开关，「界面入口」里那颗重复的已经删掉

## 🐛 修复问题

- 修复 **看板模式里布置作业**：在看板模式下点布置或修改作业，以前只闪一层遮罩、表单不出来，得退出看板才能改；现在直接在看板里弹出来，编辑和删除也不再受作业板锁定状态影响
- 修复 **便携版启动**：更新之后，开机自启、从链接唤起、重启和崩溃重启还指着上一版目录里的程序，轻则开的是旧版本、重则打不开；现在一律回到包根的启动器，由它挑当前该跑的那一版

## 📌 注意事项

- 每个架构都提供 **full（自包含）** 与 **light（依赖框架）** 两个版本：light 版需要先安装
  [.NET 10 桌面运行时](https://dotnet.microsoft.com/download/dotnet/10.0)，安装包已自带运行时，无需另装
- 当前安装包尚未使用受信代码签名证书，首次运行时 Windows SmartScreen 可能提示「未知发布者」，
  选择「更多信息 → 仍要运行」即可
- **集控默认关闭**；打开并接入后，作业与考试会以只读快照同步到集控中心——老师看得到，但改不了作业板上的内容
