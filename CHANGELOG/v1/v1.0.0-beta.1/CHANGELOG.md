# v1.0.0-beta.1

## 🚀 主要更新

- 新增 **看板模式**：一键铺满整块屏幕，一个大时钟配满屏作业，摆在桌上给同学看正合适；能按自己配的时段自动打开，作业可以只留今天要交的、一屏放不下就自动轮播，托盘里随时延长或关掉，还能用 `corkboard://display` 链接叫出来；屏幕右下角就有「布置作业」，跟左下角的长按退出在一条水平线上，不用退出去点作业板上的按钮
- 新增 **看板字号**：设置里多一页，标题、副标题、时钟、考试信息、总览表等按区域单独调大小，拖滑块时浮一个实时预览
- 新增 **考试快速布置向导**：从零排一整场考试不用再一条一条录，作息只要「一天几场、第一场几点、两场之间歇多久」；排好的安排与作息都能存成模板，换一届只改第一天是哪天
- 新增 **导出表格**：标题栏「导出」除了图片，还能把整块板子导成 Excel 直接打开的 `.xlsx`
- 新增 **作业板自动保存为图片**：把整块板面照「导出图片」的样子存成一张 PNG，可选每天一张或每次修改一张
- 新增 **首次设置引导**：第一次打开会走一遍语言、用户协议与隐私政策，再顺手选好作业板、主题和开机自启
- 新增 **「启用作业板」开关**：不需要作业板可以关掉，作业板不再出现，托盘与考试看板照旧能用
- 新增 **重新设计的「关于」页**：顶部一块会随滚动收起的大页头，下面分「应用信息／作者／鸣谢」三张卡，鸣谢里能看到在线人数与 GitHub 贡献者名单

## 💡 功能优化

- 优化 **右上角那颗锁**：现在它就是「固定窗口」开关，而且**默认锁着**——作业板的位置与大小都钉住，作业照常编辑；解锁后拖标题栏能挪板子、拉四边能改大小，这期间板面会盖一层遮罩，锁回去才能编辑
- 优化 **窗口拖动**：点击穿透与长按拖动整块板子已经移除，只剩「解锁后拖标题栏」这一条路
- 优化 **快速布置**：在总览里改了某一场的开考时刻或时长，同一天后面几场会按各自的休息自动顺延，不再各写各的；每行还能上移下移换日子，从编辑窗口进来时可以选「覆盖」还是「追加」
- 优化 **排布默认改成「区块」**：新装或没改过排布的都是区块排布，原来那个「单列」改名叫 **「多列」**
- 优化 **托盘菜单**：最上面多了一项「Corkboard」（带软件图标），点一下直接打开「关于」页；作业板那一项改成了显隐开关，板子开着时可以点「隐藏作业板」把它收起来，再点一下又出来
- 优化 **布置作业窗口**：按住窗口顶部那一行就能把整张表单挪开，底下的板子被挡住时不用先关掉
- 优化 **考试看板的时间**：总览表里的时间列、时钟下面那块时间与倒计时都改用等宽数字，数字跳秒时不左右抖、上下几行也对得齐（换过界面字体的照旧用你挑的那个字体）
- 优化 **看板模式的设置页**：「现在什么样」那张卡不再预告「今天几点会自动打开」——那个时间其实可能是后天的，当天没有时段时也会照样写出来；现在只告诉你开没开、屏上会不会是空白，「今天不再自动打开」点过之后按钮变成一句说明。时段里的「每天／工作日／周末」三颗预设按钮也去掉了，星期几自己勾

## 📌 注意事项

- 每个架构都提供 **full（自包含）** 与 **light（依赖框架）** 两个版本：light 版需要先安装
  [.NET 10 桌面运行时](https://dotnet.microsoft.com/download/dotnet/10.0)，安装包已自带运行时，无需另装
- 当前安装包尚未使用受信代码签名证书，首次运行时 Windows SmartScreen 可能提示「未知发布者」，
  选择「更多信息 → 仍要运行」即可
