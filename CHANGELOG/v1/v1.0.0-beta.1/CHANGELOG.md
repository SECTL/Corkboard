# v1.0.0-beta.1

## 🚀 主要更新

- 新增 **锁定时也能添加作业**：开了点击穿透把窗口锁住之后，锁定徽标左侧与右下角各有一颗布置作业按钮
- 新增 **导出表格**：标题栏「导出」除了图片，还能把整块板子导成 Excel 直接打开的 `.xlsx`
- 新增 **考试快速布置向导**：从零排一整场考试不用再一条一条录，几步即可全部完成
- 新增 **考试模板**：排好一次的考试可以「另存为模板」，换一届只改第一天是哪天就行
- 新增 **作息模板**：一天几场、几点开考、中间歇多久，调好一次可以存下来下次直接用
- 新增 **作业板自动保存为图片**：把整块板面照「导出图片」的样子存成一张 PNG
- 新增 **重新设计的「关于」页**：顶部一块会随滚动收起的大页头，下面分「应用信息／作者／鸣谢」三张卡，鸣谢里能看到在线人数与 GitHub 贡献者名单
- 新增 **首次设置引导**：第一次打开会走一遍语言、隐私政策与用户协议、作业板、主题、开机自启，选完直接就能用
- 新增 **「启用作业板」开关**：不要作业板的话可以关掉，主窗口不再出现，托盘与考试看板照旧能用

## 💡 功能优化

- 优化 **快速布置的「作息」**：原来要一场一场填开考时刻，现在只要三个数——一天几场、第一场几点、两场之间歇多久，并跟总览合成了一页
- 优化 **总览里改时间**：改了某一场的开考时刻或时长，同一天后面几场会按各自的休息自动往后顺延，不再各写各的
- 优化 **快速布置的写入方式**：从编辑窗口进来时可以选「覆盖看板上已有的考试」还是「追加到后面」
- 优化 **设置里的「作业板」分组**：常规 / 内容与样式 / 科目与分类 / 自动化与数据 / 窗口与收纳 / 导出
- 优化 **设置介绍**：手写设置里的「默认颜色」原来与内容默认颜色共用同一个文案键，改成「默认笔色」
- 优化 **排布默认改成「区块」**：新装或没改过排布的都是区块排布；原来那个「单列」改成 **「多列」**
- 优化 **快速布置的汇总表**：每行加了「上移／下移」，挪一下就能把这门课换到别的日子去
- 优化 **快速布置的排期**：一天几场、第一场几点、中间歇多久，与作息预设分成两行靠左排，不再挤成参差不齐的一排
- 优化 **托盘菜单**：最上面多了一项「Corkboard」（带软件图标），点一下直接打开「关于」页
- 优化 **关于页的链接**：仓库、问题反馈、组织主页、B 站、爱发电，该点哪条点哪条，都交给系统浏览器打开

## 🐛 修复问题

- 修复 **快速布置里选了一天四场、下面的表还是原来那几场**：从作息预设挑一份之后没有重新排布
- 修复 **快速布置的汇总表里时间与时长两列叠在一起**：时间列与时长列给窄了，输入框画到了右边一列上

## 📌 注意事项

- 每个架构都提供 **full（自包含）** 与 **light（依赖框架）** 两个版本：light 版需要先安装
  [.NET 10 桌面运行时](https://dotnet.microsoft.com/download/dotnet/10.0)，安装包已自带运行时，无需另装
- 当前安装包尚未使用受信代码签名证书，首次运行时 Windows SmartScreen 可能提示「未知发布者」，
  选择「更多信息 → 仍要运行」即可
