# v1.0.0-beta.1

## 🚀 主要更新

- 新增 **看板模式**：整块屏幕变成一个大时钟加满屏作业，摆在电脑上给同学看正合适；能按时段自动开关，作业只留今天要交的、一屏放不下就自动轮播，托盘里随时延长或关掉
- 新增 **看板字号**：考试看板每一处文字多大都能单独调，拖滑块时浮一个实时预览
- 新增 **考试快速布置**：几步排完一整场考试，作息只要「一天几场、几点开考、歇多久」；排好的安排和作息能存成模板
- 新增 **导出表格与自动保存图片**：「导出」多了 Excel 直接打开的 `.xlsx`，整块板面还能自动存成 PNG（每天一张或每次改动一张）
- 新增 **首次设置引导**：第一次打开走一遍语言、协议、主题与开机自启，不需要作业板的话也能顺手关掉

## 💡 功能优化

- 优化 **右上角那颗锁**：现在它是「固定窗口」开关，**默认锁着**——位置和大小都钉住，作业照常编辑；解锁后能拖标题栏、拉四边改大小，这期间板面会盖一层遮罩，锁回去才能编辑。点击穿透与长按拖动整块板子已经移除
- 优化 **快速布置**：改了某一场的时刻或时长，同一天后面几场会按各自的休息自动顺延；汇总表能上下移换日子，也能选「覆盖」还是「追加」
- 优化 **托盘菜单**：多了一项直达「关于」页，作业板那一项变成「显示／隐藏作业板」开关
- 优化 **零碎打磨**：排布默认改成「区块」（原来那个「单列」改名叫「多列」）；考试看板的时间改用等宽数字，跳秒不再左右抖；布置作业窗口按住顶部就能挪；「关于」页换成会随滚动收起的大页头

## 🐛 修复问题

- 修复 **固定窗口**：锁着的时候缩窗口，按住标题栏还是能把整个窗口拖走
- 修复 **快速布置**：选完作息下面的表不跟着变、汇总表里时间与时长两列叠在一起
- 修复 **布置作业窗口**：不先点一下输入框就点不了「取消」「保存」，内容区第一次拖手柄没反应

## 📌 注意事项

- 每个架构都提供 **full（自包含）** 与 **light（依赖框架）** 两个版本：light 版需要先安装
  [.NET 10 桌面运行时](https://dotnet.microsoft.com/download/dotnet/10.0)，安装包已自带运行时，无需另装
- 当前安装包尚未使用受信代码签名证书，首次运行时 Windows SmartScreen 可能提示「未知发布者」，
  选择「更多信息 → 仍要运行」即可
