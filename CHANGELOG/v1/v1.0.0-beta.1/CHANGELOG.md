# v1.0.0-beta.1

## 🚀 主要更新

- 新增 **锁定时也能添加作业**：开了点击穿透把窗口锁住之后，锁定徽标左侧与右下角各有一颗布置作业按钮，
  点开就能记作业，主窗口保持锁定不动；开关在「设置 → 作业板 → 常规 → 界面入口」
- 新增 **导出表格**：标题栏「导出」除了图片，还能把整块板子导成 Excel 直接打开的 `.xlsx`——
  一行一条作业，按科目分块，状态标色（今天截止 / 明天截止 / 过期 N 天），截止日期与创建时间是真日期单元格，
  表头冻结、可排序筛选；「设置 → 作业板 → 导出」里可配是否按科目分块、是否包含已清理的作业与排序方式

## 💡 功能优化

- **设置里的「作业板」分组从八页合并成六页**：常规 / 内容与样式 / 科目与分类 / 自动化与数据 / 窗口与收纳 / 导出。
  手写并进「内容与样式」、快捷标签并进「科目与分类」、清理与历史并进「自动化与数据」、收纳并进「窗口与收纳」
- **主窗口不透明度、置底到桌面、窗口圆角、长按拖动窗口、点击穿透从「基础设置」搬进「作业板 → 窗口与收纳」**，
  基础设置里不再混放作业板专属项
- 「界面入口」把原来的「顶部按钮」六项与右下角布置作业浮标合成一张卡；「区块宽度」只在「区块」排布下才显示
- 手写设置里的「默认颜色」原来与内容默认颜色共用同一个文案键，改成「默认笔色」

## 📌 注意事项

- 每个架构都提供 **full（自包含）** 与 **light（依赖框架）** 两个版本：light 版需要先安装
  [.NET 10 桌面运行时](https://dotnet.microsoft.com/download/dotnet/10.0)，安装包已自带运行时，无需另装

  选择「更多信息 → 仍要运行」即可
