# v1.0.0-alpha.1

## 🚀 主要更新

- 新增 **自动更新**：可在「设置 → 更新」里选择发布通道（Release / Beta / Alpha）与自动更新模式，支持检查、下载、安装并重启到新版本；更新清单带 Ed25519 签名校验，下载后核对 SHA-512
- 新增 **便携版启动器**：便携包根目录是 `CorkboardLauncher`，新版本装在 `app-*` 目录里切换，更新到一半失败也不会弄坏当前版本
- 新增 **Windows 安装包**：安装后自动创建开始菜单快捷方式，桌面快捷方式可选，支持静默更新
- 新增 **时空回放**：按历史日志重放作业板在任意时刻的样子，被删除的作业与编辑前的旧内容都能找回来，并可一键「还原到此刻」
- 新增 **手写便签**：支持鼠标与触控书写，带笔锋与自动矫正，内容框可拖宽拖高
- 新增 **作业截止日期与自动清理**：作业可设截止日期，到点自动把过期作业从主页面收起（数据保留，回放里仍可见）
- 新增 **富文本作业内容**：支持加粗 / 斜体 / 下划线 / 删除线、文字颜色、高亮、列表、缩进、行距、对齐、字号字体与插入表格图片
- 新增 **二级分类、快捷标签、界面字号与右下角收纳浮钮**：作业能按更细的层级归类，界面字号可随使用习惯调整
- 新增 **两种作业板排布**：单列与区块可切换，区块布局里每个区块各自定高，不跟着同行最高的那块变长
- 新增 **主窗口外观与窗口能力**：窗口圆角、不透明度、点击穿透与置底到桌面，四边（含顶部与四角）都能缩放
- 新增 **设置界面改版**：设置项改为平铺设置卡，「作业板」收成一个可展开分组，顶部「收纳」可折叠导航
- 新增 **托盘菜单**：常驻托盘，可快速显示主窗口、打开设置、重启或退出
- 新增 **作业卡片操作按钮自动收回**：点出来的编辑 / 删除按钮最多停 30 秒自动收起，不挡内容
- 新增 **导出图片与 PDF**：标题栏「导出」先选格式，PDF 分页排版、带页眉页脚与科目书签，可先预览；图片可直接复制到剪贴板；新增「设置 → 作业板 → 导出」页配置默认格式与 PDF 排版

## 📌 注意事项

- 每个架构都提供 **full（自包含）** 与 **light（依赖框架）** 两个版本：light 版需要先安装
  [.NET 10 桌面运行时](https://dotnet.microsoft.com/download/dotnet/10.0)，安装包已自带运行时，无需另装
- 当前安装包尚未使用受信代码签名证书，首次运行时 Windows SmartScreen 可能提示「未知发布者」，
  选择「更多信息 → 仍要运行」即可
